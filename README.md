# رادمهر | پلتفرم مشاوره‌ی تحصیلی و روان‌شناختی

فضای مشترک **مشاور** و **دانش‌آموز** برای ساخت، ویرایش، تأیید و پیگیری برنامه — با ثبت بازخورد دوطرفه، چک‌این روزانه و نمای خواندنی برای **والدین**.

- رابط کاربری کاملاً **فارسی و راست‌به‌چپ**، موبایل‌محور، فونت وزیرمتن، تاریخ **شمسی**
- سه نقش: مشاور / دانش‌آموز / والد (+ نقش مدیر برای مرکز چندمشاوره)
- دو حالت اجرا: **دمو** (بدون هیچ سرویسی، داده در مرورگر) و **Supabase** (واقعی، چندکاربره)
- ورود با **شماره موبایل + رمز عبور** — بدون نیاز به پیامک
- روی هر بلوک برنامه، دانش‌آموز **کسر تست (درست/کل)** و **مرحله‌ی مطالعه‌ی ۱ تا ۷** را ثبت می‌کند؛ درصد صحت و جمع هفته خودکار محاسبه می‌شود
- چک‌این روزانه: حال، انرژی، تمرکز، **خواب، مطالعه، فضای مجازی، ورزش** + **چک‌لیست تفریح‌های سالم** (۱۰ مورد، روزانه ۱ تا ۲ تیک)

---

## راه‌اندازی کامل (گیت‌هاب + Supabase + Netlify)

مسیر کامل و گام‌به‌گام در فایل [`SETUP.md`](SETUP.md) آمده است — از نصب Node تا انتشار روی Netlify و تست امنیت.
اگر GitHub Desktop را از قبل داری و می‌خواهی این پروژه را جدا/با حساب دوم بالا بیاوری: [`docs/github-desktop-fa.md`](docs/github-desktop-fa.md).

صفحه‌ی بررسی اتصال در خود اپ: `/setup` (مثلاً `http://localhost:5173/setup`).

روی ویندوز می‌توانی فقط فایل `start-dev.bat` را دوبار کلیک کنی؛ روی مک `start-dev.command`.

## ۱) اجرای سریع (حالت دمو)

```bash
npm install
npm run dev
# → http://localhost:5173
```

در این حالت هیچ سرویسی لازم نیست؛ داده‌های نمونه داخل مرورگر ساخته می‌شوند. در صفحه‌ی ورود، **ورود سریع با حساب‌های نمونه** را بزن:

| نقش | شماره | رمز |
|---|---|---|
| مشاور | ۰۹۱۲۰۰۰۰۰۰۰ | 123456 |
| دانش‌آموز (علی) | ۰۹۱۲۱۱۱۱۱۱۱ | 123456 |
| دانش‌آموز (نگار) | ۰۹۱۲۲۲۲۲۲۲۲ | 123456 |
| دانش‌آموز (سینا) | ۰۹۱۲۴۴۴۴۴۴۴ | 123456 |
| والد | ۰۹۱۲۳۳۳۳۳۳۳ | 123456 |

> برای بازگشت به داده‌ی اولیه، در صفحه‌ی ورود «بازنشانی داده‌ها» را بزن.

## ۲) اتصال به Supabase (حالت واقعی)

۱. راهنمای کامل: [`supabase/README.md`](supabase/README.md) — ساخت پروژه، اجرای `supabase/migrations/0001_init.sql`، خاموش‌کردن «Confirm email».
۲. فایل `.env` را از روی `.env.example` بساز و دو مقدار را بگذار:

```env
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

۳. `npm run dev` → نشان «متصل به Supabase» در هدر اپ ظاهر می‌شود.

ورود با موبایل به این شکل پیاده شده: شماره به ایمیل داخلی یکتا نگاشت می‌شود
(‎09121234567 → 9121234567@phone.hamghadam.local‎) و هیچ ایمیلی ارسال نمی‌شود. اگر «Confirm email» روشن باشد،
Edge Function `phone-signup` کاربر را تأییدشده می‌سازد.

## ۳) انتشار روی Netlify

```bash
npm run build          # خروجی: dist
```

- فایل `netlify.toml` حاضر است (build command، پوشه‌ی dist و ریدایرکت SPA برای React Router).
- راهنمای مرحله‌به‌مرحله (از ساخت مخزن تا Deploy و رفع اشکال): [`SETUP.md`](SETUP.md).
- در Netlify: **Add new site → Import from Git** یا کشیدن پوشه‌ی `dist` در **Deploys → Deploy manually**.
- در **Site settings → Environment variables** همان دو متغیر `VITE_SUPABASE_*` را بگذار و دوباره Deploy کن
  (متغیرها در زمان build خوانده می‌شوند).
- در Supabase → **Authentication → URL Configuration** آدرس دامنه‌ی Netlify را به عنوان Site URL بگذار.

## ۵) قابلیت‌های فعلی

**مشاور**
- داشبورد: **یادآورهای امروز** (کسی چک‌این نداده، حال پایین ثبت شده، جلسه‌ی نزدیک، برنامه‌ی منتظر تأیید)، نوار سریع دانش‌آموزان
  با درصد انجام برنامه، آمار، و پیشنهادهای هوشمند بر اساس داده
- **آزمون‌ها و دفتر اشتباهات**: ثبت درصد هر درس (یا درصد مستقیم)، مقایسه با آزمون قبلی، درصد هدف، روند میانگین وزنی،
  تفکیک علت غلط‌ها (بی‌دقتی/نبودِ دانش/کمبود زمان/بدخوانی) و افزودن سریع مورد به دفتر
- **بانک ۲۷ تمرین استاندارد** (روش مطالعه، تمرکز، اضطراب، انگیزه، خواب، آمادگی آزمون، ارتباط) + **پیشنهاد خودکار**
  بر پایه‌ی داده‌ی همان دانش‌آموز (با ذکر دلیل) + ذخیره‌ی تمرین‌های شخصی به‌عنوان قالب
- **قالب برنامه**: هر برنامه‌ی خوب را به‌عنوان قالب ذخیره کن و برای دانش‌آموز بعدی با یک کلیک و انتخاب تاریخ بساز
- پرونده‌ی دانش‌آموز با ۶ سربرگ: نمای کلی، برنامه‌ها، تمرین‌ها، چک‌این‌ها، جلسات، بازخورد
- ویرایش‌گر برنامه: شبکه‌ی هفتگی، افزودن/ویرایش آیتم (درس، نوع، مدت، اولویت، ساعت)، **کپی از هفته‌ی قبل**،
  کپی/ویرایش در حالت «کل برنامه»، تغییر سطح دسترسی دانش‌آموز، ارسال برای تأیید، فعال‌سازی، بایگانی
- تمرین‌ها (تکالیف بین جلسه) با بازخورد متنی روی هر تمرین
- جلسات: زمان، نوع (آنلاین/حضوری/تلفنی)، **خلاصه‌ی محرمانه** و **قدم‌های بعدی (قابل مشاهده برای دانش‌آموز/والد)**
- پاسخ به چک‌این‌های روزانه، کدهای دعوت یک‌بارمصرف

**دانش‌آموز**
- خانه: **یادآورهای امروز**، کارهای امروز با تیک انجام‌شدن، خلاصه‌ی آخرین آزمون، جلسه‌ی بعدی، پیام مشاور، تمرین‌های باز، وضعیت چک‌این
- **آزمون‌های من**: ثبت آزمون و درصدها، تحلیل روند، مقایسه‌ی درس‌ها با آزمون قبلی و **دفتر اشتباهات شخصی**
- برنامه: نمای هفتگی، یادداشت روی هر آیتم، **جابه‌جایی آیتم‌ها** (با ثبت خودکار در گفت‌وگو)، افزودن/ویرایش آیتم اگر
  برنامه «قابل ویرایش» باشد
- **تأیید برنامه یا درخواست اصلاح** با پیام برای مشاور
- تمرین‌ها با تغییر وضعیت (شروع نشده/در حال انجام/انجام شد) و یادداشت شخصی
- چک‌این روزانه: حال، انرژی، تمرکز، دقایق مطالعه، خواب + نمودار ۱۴ روزه و پاسخ مشاور
- گفت‌وگو با مشاور و مشاهده‌ی جلسات (فقط قدم‌های بعدی)

**والد**
- فقط خواندنی: برنامه‌ی هفتگی، درصد انجام، روند حال/مطالعه، جلسات و **گزارش هفتگی قابل چاپ/PDF**
- گفت‌وگوی امن با مشاور (بدون دسترسی به خلاصه‌ی خصوصی جلسات)

## ۶) نکات فنی

- **جدایی داده از UI**: تمام صفحات فقط با اینترفیس `Backend` کار می‌کنند؛ تغییر بک‌اند یک فایل است.
- **RLS کامل** در Supabase: دانش‌آموز فقط داده‌ی خودش، والد فقط فرزند خودش (خواندنی)، مشاور فقط پرونده‌های وصل‌شده.
- تقویم شمسی و اعداد فارسی بدون وابستگی خارجی (`src/lib/jalali.ts`).
- `npm run typecheck` و `npm run build` برای بررسی سلامت پروژه.
- `npm test` ده تست دود و قابلیت را اجرا می‌کند: ورود، داشبورد هر سه نقش، صفحه‌ی آزمون‌ها، یادآورها، بانک تمرین و گزارش والد.
- **جدول‌های جدید Supabase**: `0002_assessments_templates.sql` (آزمون‌ها، دفتر اشتباهات، قالب‌ها + RLS + تابع
  `apply_plan_template`) را بعد از مایگریشن اول اجرا کن.

## ۷) گام‌های بعدی پیشنهادی

جزئیات و پرسش‌های باز در [`docs/roadmap-fa.md`](docs/roadmap-fa.md) آمده است. خلاصه:

1. اطلاع‌رسانی واقعی (پیامک/پوش): همین منطق یادآورها را به Edge Function + کاوه‌نگار وصل کنیم
2. ثبت‌نام/ورود با **کد یک‌بارمصرف پیامکی** (جای رمز عبور) به‌عنوان گزینه‌ی دوم
3. اتاق جلسه‌ی آنلاین یا اتصال به ویدیوکنفرانس + یادداشت زمان‌دار
4. دفتر اشتباهات آزمون، ثبت نمرات و آزمون‌های آزمایشی، پیشرفت به تفکیک درس
5. نقش «مدیر مرکز»: مدیریت مشاوران، تخصیص دانش‌آموز، گزارش عملکرد مرکز
6. اپ موبایل/PWA (نصب روی گوشی + حالت آفلاین چک‌این)
